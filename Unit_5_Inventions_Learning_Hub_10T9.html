Present Perfect · Hiện tại hoàn thành
FormStructureExample
+S + have/has + V3/edI have installed the app.
−S + have/has not + V3/edShe has not charged her phone.
?Have/Has + S + V3/ed?Have you used AI?

Have: I, you, we, they. Has: he, she, it.

Ba cách dùng: kết quả còn liên quan hiện tại; hành động bắt đầu trong quá khứ và còn tiếp diễn; việc vừa hoàn thành. Dấu hiệu: just, already, yet, recently, lately, ever, never, so far, up to now, several times.

Since + mốc: since 2020. For + khoảng: for three years.

V3 cần nhớ: use → used; invent → invented; buy → bought; see → seen; meet → met; do → done; write → written; go → gone.

Gerund & To-infinitive

V-ing: enjoy, avoid, finish, suggest, practise, mind, dislike, consider, admit, deny, miss, postpone, quit, recommend, risk, detest. V-ing có thể làm chủ ngữ: Using AI can save time.

To + V: decide, want, hope, plan, need, learn, agree, afford, expect, manage, promise, refuse, offer, prepare, would like, arrange, appear, demand, deserve, fail, hesitate, mean (intend), pretend, seem, threaten, volunteer, wait, wish, would love.

It is + adj + to V: It is easy to use this app.

Allow / permit / advise + O + to V: This app allows users to communicate. Khi không có tân ngữ chỉ người, có thể dùng V-ing: They allow using tablets. Recommend + V-ing hoặc recommend that + S + V là lựa chọn tự nhiên.

Like, love, hate có thể đi với cả V-ing và to V.
